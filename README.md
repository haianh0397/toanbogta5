# HƯỚNG DẪN DÙNG CLOUD GTA V TẠI NHÀ & RA QUÁN NET TẢI FILE

Hệ thống cho phép bạn:
* **Ở nhà:** Đăng tải các file mod GTA 5 thực tế (tiếng súng `.oiv`, preset ReShade `.ini`, file crash dump, mã nguồn script FiveM) lên server cá nhân.
* **Ra quán net:** Chỉ cần mở link trên trình duyệt quán net là tải về toàn bộ file chỉ với 1 click!

---

## 🚀 CÁCH SỬ DỤNG CỰC KỲ ĐƠN GIẢN

### BƯỚC 1: Ở NHÀ - KHỞI ĐỘNG VÀ TẢI FILE LÊN
1. Nhấp đúp vào file: **`CHAY_SERVER_TAI_NHA.bat`** (Màn hình đen sẽ hiện ra báo server đang chạy ở cổng 3000).
2. Mở trình duyệt web của bạn và vào: **`http://localhost:3000`**
3. Bấm nút **"ĐĂNG TẢI FILE"** ở góc trên:
   * Chọn file từ máy tính của bạn (hỗ trợ mọi định dạng `.zip`, `.rar`, `.oiv`, `.ini`, `.wav`, `.lua`, `.dmp`,...).
   * Chọn đúng chuyên mục (Tiếng súng, ReShade, File Dump, hoặc Mã nguồn).
   * Bấm **"Tải Lên Lưu Trữ"** ➔ File thật sẽ được lưu vĩnh viễn trong thư mục `uploads/`.

---

### BƯỚC 2: TẠO LINK ĐỂ MANG RA QUÁN NET
1. Nhấp đúp vào file: **`MO_LINK_RA_QUAN_NET.bat`**
2. Cửa sổ sẽ tự động tạo một đường link online miễn phí (có dạng: `https://xxxx.trycloudflare.com`).
3. Bạn **sao chép đường link này gửi vào Zalo / Messenger hoặc lưu vào điện thoại**.
4. *(Giữ máy tính ở nhà bật và mở 2 cửa sổ đó khi bạn đi ra quán net).*

---

### BƯỚC 3: KHI RA QUÁN NET
1. Ngồi vào máy tính quán net, mở trình duyệt (Google Chrome / Cốc Cốc).
2. Dán đường link `https://xxxx.trycloudflare.com` bạn vừa lưu trên điện thoại vào.
3. Toàn bộ file tiếng súng, reshade, dump, source bạn đã upload ở nhà sẽ xuất hiện đầy đủ!
4. Nhấp nút **"Tải Về"** ở từng file để tải trực tiếp xuống máy quán net và chơi game!
